# 🎙️ Albus Audio — Serverless P2P Mesh Рация на Rust (2026)

**Albus** — высокопроизводительная, децентрализованная голосовая рация на чистом Rust. Работает напрямую между пирами без выделенных серверов, пробивает любые типы NAT и роутеров благодаря сетевому стеку **Iroh (QUIC)**, обеспечивает сквозное шифрование (**E2EE**) и передаёт звук студийного качества с ультранизкой задержкой.

---

## ⚡ Ключевые возможности

* **Полная децентрализация (Zero-Server Architecture):** Никаких центральных медиа-серверов. Каждый клиент — полноправный узел Mesh-сети.
* **Iroh P2P Full-Mesh:** Подключение по криптографическому **NodeID** в 1 клик. Автоматический обход NAT, STUN Hole Punching и прозрачный Fallback на защищённые релеи (связь работает даже через жесткий мобильный 4G/LTE и провайдерский CGNAT).
* **Сквозное шифрование (E2EE):** Все датаграммы голоса зашифрованы алгоритмами **ChaCha20-Poly1305 / AES-GCM** поверх QUIC (TLS 1.3). Ни провайдер, ни релеи не могут перехватить разговор.
* **Бесшовная миграция хоста (Self-Healing):** При аварийном выходе создателя комнаты сеть моментально и единогласно переизбирает нового лидера без разрыва связи и вылета участников.
* **Студийный DSP-тракт:**
  * **Opus 64 kbps HQ VoIP:** Широкополосная передача речи (48 кГц Fullband).
  * **Адаптивный Noise Gate:** Аппаратное отсечение шума кулеров ПК, дыхания и эха комнаты в паузах речи (порог -44 dBFS).
  * **Встроенный ресэмплер:** Линейная интерполяция между любыми частотами звуковых карт (44.1, 48, 96, 192 кГц) — никакого «эффекта бурундука» или замедления звука.
  * **Формат вывода как у карты:** поток открывается в родном формате устройства (f32, i32 или i16 — что карта реально принимает), поэтому звук не пропадает на нестандартном оборудовании; ошибка открытия динамиков или микрофона пишется в консоль. На виртуальных многоканальных выходах (7.1, например Razer) звук идёт в две колонки, а не дублируется во все восемь, и такой выход получает поток в i32 — на f32 эти драйверы воспроизводят речь со свистом.
  * **Автоматическая регулировка усиления (AGC):** тихий микрофон подтягивается до целевого уровня (RMS −20 dBFS), громкий — осаживается, поэтому свой голос слышно так же громко, как в Discord, без ручной настройки.
  * **Честный dB Boost (до +18 дБ на собеседника):** регулятор громкости участника в децибелах (−30…+18) плюс общая громкость собеседников до 300 %.
  * **Пиковый лимитер (−1.0 dBFS) на общем миксе:** голоса складываются, а ограничивается готовый микс — персональный буст не съедается, и несколько громких собеседников не перегружают выход.
* **Глобальный PTT (Push-To-Talk):** Перехват хоткеев на уровне ядра Windows (`GetAsyncKeyState`) — рация работает прямо в играх при свернутом окне.
* **Hands-Free режим:** Удобный тумблер постоянной передачи без залипаний.
* **Трансляция экрана (1080p/1440p, 30 или 60 fps):** захват через DXGI Desktop Duplication, аппаратный H.264 (NVENC/AMF/QSV) через Media Foundation, передача отдельным iroh-соединением (`discordrf-video/1`) — видео не душит голос. Частота выбирается до старта (по умолчанию 60), в строке трансляции видны fps показа и fps кодирования, а в окне зрителя — ещё и миллисекунды показа (декод / чтение с GPU / картинка).
* **Друзья и текстовый чат (DM):** список друзей по NodeID, входящие заявки и личные сообщения. Чат — только на время сессии (не пишется на диск) и только с друзьями; сообщения идут тем же iroh-каналом, что и заявки.
* **Интерфейс:** тёмная оболочка без лишних рамок — консоль эфира слева (диск рации, трансляция, микшер, линия, PTT) и рейл справа одной карточкой: комната, свой NodeID с копированием, участники и друзья. Настройки и чат — оверлеи поверх окна, тёмный системный заголовок Windows.
* **Монолитный билд:** Все изображения (`assets/logo.png`, `assets/icon.png`) вшиваются прямо в исполняемый файл через `include_bytes!`.

📦 Сборка и запуск

🪟 Windows (10 / 11)

Сборка в нативном оптимизированном режиме:

Powershell

cargo build --release
.\target\release\albus.exe

🐧 Linux / WSL2

Установка системных аудио- и графических библиотек (Ubuntu/Debian):

Bash
sudo apt update && sudo apt install -y pkg-config libasound2-dev libx11-dev libxcursor-dev \
libxrandr-dev libxi-dev libgl1-mesa-dev libxkbcommon-dev libssl-dev libclang-dev

cargo build --release
./target/release/albus

🚀 Как пользоваться

Создание комнаты (Хост):
Запустите приложение.
Скопируйте свой NodeID: кнопка «Поделиться» в шапке или «Копировать» в секции «Мой NodeID» — появится тост о копировании.
Отправьте скопированный ключ друзьям.

Подключение (Клиент):
Вставьте полученный NodeID в поле «NodeID собеседника» в секции «Комната».
Нажмите «Войти». Соединение установится за доли секунды.

Разговор:
Зажмите назначенную кнопку (по умолчанию боковая кнопка мыши Mouse 4; назначенная кнопка подписана справа на PTT-пилюле) или включите тумблер «Постоянный эфир».
Говорить можно прямо из любых полноэкранных игр — рация перехватывает хоткеи глобально во всей ОС.

Трансляция экрана:
1. Нажмите «Запустить» в карточке «Трансляция» — появится превью.
2. Клик по превью открывает отдельное окно «Albus — трансляция»: его можно растянуть под себя, кнопка «На весь экран» разворачивает на весь монитор (Esc — выход).
3. Все, кто уже в комнате, видят поток автоматически — у них окно просмотра открывается само.
