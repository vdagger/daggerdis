# 🎙️ Albus Audio — Serverless P2P Mesh Рация на Rust (2026)

**Albus** — высокопроизводительная, децентрализованная голосовая рация на чистом Rust. Работает напрямую между пирами без выделенных серверов, пробивает любые типы NAT и роутеров благодаря сетевому стеку **Iroh (QUIC)**, обеспечивает сквозное шифрование (**E2EE**) и передаёт звук студийного качества с ультранизкой задержкой.

---

## ⚡ Ключевые возможности

* **Полная децентрализация (Zero-Server Architecture):** Никаких центральных медиа-серверов. Каждый клиент — полноправный узел Mesh-сети.
* **Iroh P2P Full-Mesh:** Подключение по криптографическому **NodeID** в 1 клик. Автоматический обход NAT, STUN Hole Punching и прозрачный Fallback на защищённые релеи (связь работает даже через жесткий мобильный 4G/LTE и провайдерский CGNAT).
* **Сквозное шифрование (E2EE):** Все датаграммы голоса зашифрованы алгоритмами **ChaCha20-Poly1305 / AES-GCM** поверх QUIC (TLS 1.3). Ни провайдер, ни релеи не могут перехватить разговор.
* **Бесшовная миграция хоста (Self-Healing):** При аварийном выходе создателя комнаты сеть моментально и единогласно переизбирает нового лидера без разрыва связи и вылета участников.
* **Студийный DSP-тракт:**
  * **Opus 64 kbps HQ VoIP:** Широкополосная передача речи (48 кГц Fullband).
  * **Адаптивный Noise Gate:** Аппаратное отсечение шума кулеров ПК, дыхания и эха комнаты в паузах речи (порог -44 dBFS).
  * **Встроенный ресэмплер:** Линейная интерполяция между любыми частотами звуковых карт (44.1, 48, 96, 192 кГц) — никакого «эффекта бурундука» или замедления звука.
  * **Честный dB Boost (+18 дБ):** Логарифмическое усиление тихих собеседников до 8 раз.
  * **Soft-Knee Limiter (-1.0 dBFS):** Прозрачный пиковый лимитер, исключающий перегруз и хрипы.
* **Глобальный PTT (Push-To-Talk):** Перехват хоткеев на уровне ядра Windows (`GetAsyncKeyState`) — рация работает прямо в играх при свернутом окне.
* **Hands-Free режим:** Удобный тумблер постоянной передачи без залипаний.
* **Монолитный билд:** Все изображения (`assets/logo.png`, `assets/icon.png`) вшиваются прямо в исполняемый файл через `include_bytes!`.

📦 Сборка и запуск

🪟 Windows (10 / 11)

Сборка в нативном оптимизированном режиме:

Powershell

cargo build --release
.\target\release\albus.exe

🐧 Linux / WSL2

Установка системных аудио- и графических библиотек (Ubuntu/Debian):

Bash
sudo apt update && sudo apt install -y pkg-config libasound2-dev libx11-dev libxcursor-dev \
libxrandr-dev libxi-dev libgl1-mesa-dev libxkbcommon-dev libssl-dev libclang-dev

cargo build --release
./target/release/albus

🚀 Как пользоваться

Создание комнаты (Хост):
Запустите приложение.
Нажмите кнопку 📋 рядом с вашим ID комнаты (NodeID) в верхней карточке.
Отправьте скопированный ключ друзьям.

Подключение (Клиент):
Вставьте полученный NodeID в поле «Вставьте NodeID...».
Нажмите 🔗 Войти. Соединение установится за доли секунды.

Разговор:
Зажмите назначенную клавишу (по умолчанию боковая кнопка мыши Mouse 4) или переключите тумблер «Постоянная передача (Hands-Free)».
Говорить можно прямо из любых полноэкранных игр — рация перехватывает хоткеи глобально во всей ОС.
