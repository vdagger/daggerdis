**Наблюдения по коду**
- `restart_playback_stream` (gui/stream_control.rs:64) обнуляет старый поток до
  создания нового: при ошибке (устройство занято/выдернуто) звук не возвращается.
  Во входном тракте наоборот — сначала сборка, потом замена. Кандидат на фикс.
- `VideoSession::last_error` и `RemoteView::last_error` — мёртвый код: ошибки
  декодирования нигде не отображаются, окно просто пустое.
- Hot-plug аудиоустройств отсутствует: список устройств читается при старте и
  при ручной смене в настройках.
- `gui/mod.rs` — 2 317 строк, видео-маршруты, оверлеи, настройки и консоль в
  одном `impl`; напрашивается разбиение по файлам.
- Тесты есть только на «чистые» модули; GUI, `iroh_service`, Windows-видео не
  покрыты.

**Решения**

- Журналы — три уровня: `STATE.md` (где мы + очередь), `DEVLOG.md` (хронология),
  `ROADMAP.md` (этапы). Не дублировать содержимое `CLAUDE.md`.
- Перед любой правкой кода — коммит или тег; откат через `git reset --hard <тег>`.
- Сборка/тесты — через перенаправление в файл (пайпы в песочнице запрещены).
