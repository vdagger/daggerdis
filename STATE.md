## Что это за проект

P2P голосовая рация и клиент для созвонов: чистый Rust, транспорт iroh/QUIC
(датаграммы для голоса, отдельное соединение для видео), GUI на eframe/egui.
Без серверов: комнату держит один из участников, при его выходе — миграция хоста.
Уже работает: голос (2 входа, эффекты, PTT), звонки, друзья, онлайн-статус, DM-чат,
трансляция экрана 1080p/1440p 30/60 fps звездой publisher → host → viewers.

- Объём: ~15 400 строк в `src/` (46 файлов), крупнейшие — `gui/mod.rs` (2 317),
  `network/video_link.rs` (2 043), `calls.rs` (898).
- Тесты: 95 юнит-тестов (config, calls, txbus, mixer, message, video_link,
  video_directory, presence, room, audio) — все зелёные на 2026-11-21.
- Платформы: Windows — основной таргет (видео только Windows);
  Linux/macOS собираются частично, готовность — в `ROADMAP.md` → «Кроссплатформенность».

## Известные проблемы и долги

- **Hot-plug проверен не до конца:** сценарий «выбранное устройство выдернули →
  откат на устройство по умолчанию» покрыт юнит-тестами плана
  (`devices::plan_device_update`) и кодом отката, но живьём не воспроизведён:
  Windows после нескольких `disable/enable` ответила «Device is pending system
  reboot» и отключить выбранную карту не дала. Проверить руками: выдернуть
  USB-карту при работающем приложении — должен быть тост
  «Устройство отключено: …», звук уходит на устройство по умолчанию.
- **Выдёргивание драйвера чтением конфигурации не лечится:** если выдернуть карту
  насовсем, `config.ini` сохранит откат (устройство по умолчанию), и после
  возврата карты выбор сам не вернётся — надо выбрать руками.
- **`gui/mod.rs` — монолит ~2 450 строк:** видео-логика маршрутов, оверлеи,
  настройки и консоль в одном `impl RadioApp`; вынесение по файлам — первоочередной
  технический долг.
- **Тестов нет на GUI, network/iroh_service, video-win** — только чистые модули.
- Старый конфиг `config.ini` совместим, но ключи `mic_processing` / `input*_profile`
  остаются «мёртвыми» для новых установок.
- Проверить на живой машине после пачки 21.11: мьют (кнопка и `Ctrl+M`),
  тост при ошибке переключения динамиков, «Войти в комнату» из строки друга,
  имена участников, сообщение в чёрном окне видео вместо пустоты.

## Не делать (противоречит архитектуре)

- Сервер, аккаунты, офлайн-доставка сообщений — ломает zero-server и E2EE.
- Автосохранение истории чата на диск — явное решение проекта (chat.rs:1-2).
- Свой UDP/STUN-фолбэк или вход по «IP:порт» — работа iroh и анти-имперсонация
  (`sender_id ↔ NodeID`) держатся на этом.
